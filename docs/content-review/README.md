# FAYROZ — مراجعة المحتوى على دفعات

المستخدم اعتمد13دفعة وصرح بمراجعة المعلومات وتعديلها وما يرتبط بها، وحفظ كل دفعة ثم التجميع النهائي مرة واحدة. لا يلزم طلب الموافقة مجددًا على التصحيحات داخل النطاق.

## تعليمات العمل المعتمدة

- المعلومة تخدم اختيارًا أو خطوة تنفيذ أو فحصًا أو تجنب خطأ؛ احذف الحشو والتكرار دون حذف شروط التطبيق.
- اسم السوق أولًا؛ فسّر المصطلح الفني عند الحاجة. جمل مباشرة ومركزة بلغة عربية مفهومة في مصر.
- رتب الإجراءات: قبل البدء، الخامات والأدوات المهمة، الخطوات، شروط التطبيق، الفحص، الأخطاء والتصرف، المراجع.
- افصل مسارات الأنظمة البديلة عن الخطوات المطلوبة لكل الأعمال؛ لا ينفذ المستخدم كل البدائل بالتتابع.
- راجع الخامات والمقاسات والصور والاستلامات والعيوب المرتبطة بالدفعة؛ حدث البطاقة المشتركة مرة واحدة واحتفظ بمعرفها.
- تحقق من المصادر الأولية الرسمية. المصدر العام ليس إثباتًا لكل رقم. المنتج الأجنبي مثال خاص به وليس كودًا مصريًا.
- وثق الناشر والصنف والنظام وإصدار المستند والصفحة والقسم والرابط وتاريخ المراجعة وحدود التعميم. عند غياب سند لرقم افصل المثال عن الاشتراط أو أحل القيمة لمستند تصميم محدد.
- حافظ على معرفات السجلات وروابطها والمفضلة والتعديلات الشخصية؛ راجع معنى أي نقطة محررة إذا تغيرت قائمة أصلها.
- الاختبارات قبل إخفاء الأعمال توضع قبل الإغلاق؛ لا تصنفها جميعًا بعد التنفيذ.
- كل دفعة لها تقرير مستقل وسجل تغييرات واختبارات مناسبة. الأصل المرجعي هو رأس فرع codex/content-review-batches، وليس ملفات مؤقتة في شات قديم.
- اقرأ QUEUE.json قبل العمل. لا تبدأ الدفعة التالية إذا كان بناء الدفعة السابقة فاشلًا؛ أصلح السابق أولًا.
- احفظ كل دفعة في commit مستقل؛ حدث سجل الحالة بعد نجاح البناء والفحص. لا تعدل الدفعات الأخرى إلا بطاقة مشتركة أو تكامل ضروري موثق.
- بعد13دفعة راجع توافق العزل/السباكة، الجبس/الكهرباء، الواجهات/الشبابيك، الأرضيات/الأبواب، ثم ابْنِ النسخة المجمعة واختبرها. لا تدعِ اختبار جهاز فعلي إذا لم يحصل.

## المصادر والقيود

التصاميم الخاصة بالمشروع واعتمادات المورد الفعلي لا يمكن استبدالها بإرشادات عامة. سجل الحالة العلمية بصراحة: موثق لمنتج بعينه، مبدأ تنفيذي، مثال حسابي، أو يحتاج مستند المشروع. لا تنسب اعتماد كود لأي قيمة دون قراءة مستنده وبنده وإصداره.

تغييرات الدفعة الأولى تحت الفحص؛ هذه الوثيقة لا تعني أن13دفعة اكتملت أو أن برنامجًا جديدًا صدر.

## المتابعة

QUEUE.json يحمل الحالات وعناوين الدفعات وأقسامها. تقرير BATCH01.md يحفظ بداية المراجعة. النسخة النهائية تصدر بعد اكتمال الطابور.
